# Kanban Board Tracker

Локальная интерактивная Kanban-доска задач для совместной работы человека и AI-агентов (Gemini, Claude).

## Описание
Этот инструмент позволяет визуализировать и управлять задачами проекта, сохраненными в виде обычных Markdown-файлов в папке `.agents/tasks/`. Перетаскивание задач на доске автоматически перемещает соответствующие файлы на диске. Любые ручные правки файлов задач в вашей IDE мгновенно отображаются на доске благодаря SSE (Server-Sent Events) синхронизации.

## Структура проекта
* `tracker/` — веб-приложение доски (Node.js сервер и фронтенд).
* `.agents/` — регламенты работы агентов, готовые инструкции (`instructions/`) и навыки (`skills/`).
* `.agents/tasks/` — директория с задачами (колонки `Backlog`, `To do`, `Done`).

## Запуск
Подробную информацию по настройке проекта, смене названия и порта, а также управлению сервером разработки читайте в файле [SETUP.md](SETUP.md).

Быстрый старт:
```bash
cd tracker
node server.cjs
```
После чего откройте [http://localhost:5000](http://localhost:5000).
