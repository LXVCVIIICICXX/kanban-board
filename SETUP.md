# Инструкция по настройке и запуску Kanban-доски

Этот проект представляет собой локальную Kanban-доску для управления задачами проекта силами разработчиков и AI-агентов (Gemini, Claude). Доска хранит задачи в виде простых Markdown-файлов в папке `.agents/tasks/` и синхронизирует изменения в реальном времени.

---

## 1. Конфигурация проекта

Вся настройка доски сосредоточена в файле [tracker/config.js](file:///Users/lexus/Documents/Kanban/tracker/config.js). 

Откройте его и настройте параметры под ваш проект:

```javascript
module.exports = {
  // Название проекта (отображается в заголовке доски)
  PROJECT_NAME: 'Название Вашего Проекта',

  // Порт, на котором запускается Kanban-трекер
  TRACKER_PORT: 5000,

  // Колонки канбан-доски (порядок отображения и имена папок)
  TASK_FOLDERS: ['Backlog', 'To do', 'Done'],

  // Папка для хранения вложений задач (внутри .agents/tasks/)
  ATTACHMENTS_FOLDER: 'Файлы',

  // Список доступных исполнителей (для выпадающих списков в UI)
  ASSIGNEES: ['Gemini', 'Claude', 'Human', 'Both'],

  // Опционально: порт и команды управления сервером вашего проекта (если нужно запускать из UI)
  APP_PORT: null, // например, 8000 или 3000
  APP_START_CMD: '', // команда запуска, например, "npm run dev"
  APP_STOP_CMD: '', // команда остановки (по умолчанию завершает процесс на APP_PORT)
};
```

### Настройка переменных окружения (опционально)
Порт трекера и название проекта также можно переопределить через переменные окружения:
* `TRACKER_PORT` — переопределяет порт запуска сервера.
* `PROJECT_NAME` — переопределяет название проекта в доске.

---

## 2. Установка зависимостей и запуск

Сервер доски написан на Node.js и не требует сторонних npm-зависимостей (использует стандартные библиотеки Node.js: `http`, `fs`, `path`, `crypto`, `child_process`).

### Запуск трекера задач:
Перейдите в папку `tracker` и запустите сервер:
```bash
cd tracker
node server.cjs
```

После этого откройте в браузере:
* **Kanban-доска:** [http://localhost:5000](http://localhost:5000) (или настроенный вами порт).

---

## 3. Как это работает

1. **Задачи как файлы:** Каждая карточка на доске — это `.md`-файл в папке [`.agents/tasks/<Имя колонки>/`](file:///Users/lexus/Documents/Kanban/.agents/tasks/).
2. **Метаданные:** В начале файла описываются атрибуты задачи:
   ```markdown
   # Название задачи
   <!-- id: a1b2c3d4 -->
   <!-- assignee: Claude -->
   <!-- dependencies: x9y8z7w6 -->
   ```
3. **Двусторонняя синхронизация:** 
   * Перетаскивание карточек в браузере физически перемещает файлы между папками `Backlog`, `To do` и `Done`.
   * Изменение файлов редактором или скриптами мгновенно обновляет доску в браузере (через SSE-соединение к серверу).
